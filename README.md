# TNTmanagerSimulator
《时代少年团经纪人模拟器》是我在看见朋友在《灵光》APP中游玩类似游戏，因此突发兴致用纯AI搓了一个同款。本html保证纯AI无手搓。经不严谨的测试，俺寻思这款游戏性尚佳，难度适中，因此严肃分享在GitHub上。


屏幕前的各位，记得多多支持灵光的原版哦！

# 超困难的使用方法
1.下载index.html。  
2.双击打开。

### 《TNTmanagerSimulator》如今已经上传GitHub Pages。输入网址：https://tyanbilibili.github.io/TNTmanagerSimulator/ 即可在线游玩！

（ps：我发现iOS设备上能用的浏览器比较少，而QQ浏览器每次都会清除浏览器缓存导致每次都没法存档。没招了，不过我倒也不用iOS设备测试，就当没看到不修了😋）

# 目前最新版本：1.1.0 （2026-08-29）
### 1.0.10 → 1.1.0 更新内容：
· 随机事件 buff/debuff 倍率更激进：训练加成最高可达 3 倍（赚钱/涨粉/休息同理），并按事件性质区分短效/长效（效果越强持续越短）；

· 新增强力但带代价的复杂事件（分成制收益、双代言、魔鬼教官、站姐内斗、暗雷条款等）；

· 事件保底调整为连续 2 天无事件则第 3 天必出现；

· 成员初始实力/名气/粉丝全部随机（实力 ±7、名气 ±5、粉丝 85%~115%），每局开局不同；

· 首页改为占满全屏的居中布局（参考花样下棋），不再留有半边空白；

· 手机端新手教程卡片自动避让要点的按钮，不再遮挡。

· 结算日志成员行补上「钱」字标签（如「钱+20,573 ·粉+2,152」），金额一目了然；

· 执行日程资金不足时自动借款按 2万/5万/10万 档位取整（缺 1 万也会借 2 万），不再只借零头；

· 事件结果新增玻璃碎裂特效（参考花样下棋，碎片+裂纹+闪光），正向结果时播放；

· 「查看图鉴」按钮移到解锁事件与历史回顾之间并加大，入口更醒目。
